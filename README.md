FlatCAM: 2D Computer-Aided PCB Manufacturing
============================================

FlatCAM is a program for preparing CNC jobs for making PCBs on a CNC router.
Among other things, it can take a Gerber file generated by your favorite PCB
CAD program and create G-Code for isolation routing.

## Requirements

- **Python** 3.10–3.13 (tested on 3.13)
- **PySide6** (Qt 6 bindings)
- NumPy, SciPy, Matplotlib, Shapely 2.x, Rtree, svg.path, simplejson
- On Windows, `pywin32` is recommended for AppData path resolution

## Install

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
# Windows only:
pip install pywin32
```

## Run

```bash
python flatcam
# or, after install:
# flatcam
```

## Migration notes (PyQt4 → PySide6)

This tree has been ported from **PyQt4** to **PySide6** for modern Python:

| Area | Change |
|------|--------|
| GUI toolkit | `PyQt4` → `PySide6` (`QtCore` / `QtGui` / `QtWidgets`) |
| Signals | `pyqtSignal` → `Signal` |
| Matplotlib | `Qt4Agg` → `QtAgg` (`backend_qtagg`) |
| File dialogs | Return `(path, filter)` tuples; wrappers unwrap path strings |
| Shapely | `cascaded_union` → `unary_union`; multi-geometry iteration via `.geoms` |
| NumPy | `Inf` → `inf` |
| Python | `pkgutil.find_module` → `importlib.import_module` |
